# 🍅 Promodoro

A simple and beautiful Pomodoro timer app for macOS and iOS.

![SwiftUI](https://img.shields.io/badge/SwiftUI-blue?logo=swift&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-macOS%20%7C%20iOS-lightgrey)

## Features

- ⏱️ 25-minute focus sessions with customizable breaks
- 🔔 Notifications when sessions complete
- 🎵 Satisfying sound effects
- ⚙️ Customizable timer durations
- 📊 Track completed pomodoros

## Requirements

- macOS 14.0+ (MacBook)
- iOS 17.0+ (iPhone)
- Xcode 15.0+

## Installation

1. Clone the repository
2. Open `Promodoro.xcodeproj` in Xcode
3. Select your target device (Mac or iPhone)
4. Build and run (⌘R)
